# Patch Manager

App React Native para gerenciamento de patch panels.

## Funcionalidades
- Gerenciar salas e patch panels
- Documentar conexões
- Buscar portas e conexões

## Tecnologias
- React Native
- Expo

## Como executar
```bash
npm install
npm start
```

Acesse: https://testes-app.github.io/patch-manager/
